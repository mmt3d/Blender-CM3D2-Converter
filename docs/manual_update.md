# エクステンションの手動更新方法

`v2026.8.29` 以前からのエクステンション更新は失敗するため、こちらの方法で手動更新をお試しください。  
それ以降は問題なくエクステンション更新できます。

Blenderを落とした状態で、下記手順でお願いします。

1. [Releases](https://github.com/mmt3d/Blender-CM3D2-Converter/releases) より最新版の `*-extension.zip` をダウンロード
2. 下記ディレクトリを開く (※Blenderバージョンによりパスを読み替えてください)
  ```
  %APPDATA%\Blender Foundation\Blender\5.2\extensions\mmt3d_github_io\cm3d2_converter
  ```
3. zipファイルの中身をそのままコピー (全て上書き)
